I'm an **SQA engineer** who spent nearly five years at **Samsung Electronics America** validating **SpaceX Starlink** satellite and mobile network quality and building Python test automation,

## 🧭 How I Work

```text
Problem Definition
→ Data Check & Labeling QA
→ Baseline
→ Failure Analysis
→ One-Variable-at-a-Time Improvement
→ Frozen Test (once)
→ Regression Test
→ Serving & Deployment
→ Documentation (KR / EN)
→ Explain it to the customer
```

> One thing QA taught me — **"an improvement you didn't measure isn't an improvement."**
> So every project records its baseline, failure causes, size of improvement and remaining limits, in numbers.
